Troubleshoot sound

Android: Settings → search “Text-to-speech” → set the engine to Speech Services by Google, tap its gear → Install voice data → download English. Then fully close Chrome and reopen this page.
iPhone: turn off the silent switch; Settings → Accessibility → Spoken Content → Voices.
